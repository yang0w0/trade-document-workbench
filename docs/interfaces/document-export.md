# 单据生成与导出接口

**Owner:** `features/trade-documents/`  
**Contract ID:** `trade-documents.export.v1`  
**Status:** `proposed`  
**Consumers:** 网页载体和贸易单据模块页面

## 请求概念

- `recordId`: 已核对的贸易记录。
- `documents[]`: 用户选择生成的类型，例如 `INV`、`PL`。
- `format`: `xlsx`、`docx` 或 `pdf`。
- `templateId`: 用户确认且与输出类型/格式匹配的模板 ID。
- `options`: 仅包含已定义且由模板支持的导出选项。

## 成功响应

返回每个输出文件的文档类型、格式、文件名、MIME 类型和可由本地网页下载的文件引用。文件应在本机处理。模板中的固定文本、公式、样式和打印设置由模板适配器负责。

## 缺项和错误

- 若缺少模板必需字段，返回字段路径、字段名称和缺失原因；不可静默填入猜测值。
- 对不一致或未确认值，提示用户先回到核对界面。
- 模板格式不匹配、模板结构不受支持或导出失败时，返回可读错误且不提供残缺文件作为成功结果。
- PDF 输出的版式保留能力需要逐种模板验证；本契约不承诺所有 Excel/Word 模板可无损转换。

## 模板和格式约定

模板属于贸易单据模块管理的数据，不归网页载体或集装箱模块所有。Excel/Word/PDF 是期望的用户导出选择；具体输入/输出支持矩阵、公式保留、字体和分页行为，需按用户提供的样例模板确认并记录。

## 兼容与验证

同一输出类型和格式使用稳定的模板 ID 与字段映射版本。改变模板必填字段或生成结果语义时更新主版本。标为 `verified` 前，应使用经确认的 Excel、Word、PDF 模板分别检查成功文件、缺字段提示和不支持模板的错误。
