# 节省额度的单据识别测试

保持识别、来源证据和验收可靠，减少模型输入与重复执行。仅适用本项目单据模块；磁盘读取、本机 OCR/转换耗时不能直接当作模型额度。

## 按需读取与输出

- 先读项目/模块协作规则，定位相关入口、测试和报告。已读且未变化的代码、技能和说明复用当前上下文；规则要求重读或上下文缺失时再读。只加载当前任务需要的技能及引用。
- 用 `rg -n` 定位后读取相关函数或行段；限定模块和文件类型，排除虚拟环境、依赖、vendor、旧产物和缓存。首次读取也不输出整文件；出现截断先收窄查询。
- 本机批量盘点、比较与汇总。默认仅返回文件类型/数量、通过/失败/待核对数、缓存命中/解析/OCR 次数及失败差异，不输出成功候选、文档全文或完整测试日志。
- 每批最多展开 5 个异常文件，每个最多 3 段约 160 字原文；详情本地保存，需要时按字段/页码/单元格读取。正常进度和交付简短说明结果、未覆盖项与报告位置，不重复叙述过程。

## 分层复用

| 层级 | 缓存内容 | 失效依据 |
|---|---|---|
| 读取层 | 文本行、表格、页码/坐标、读取方法、OCR 分数 | 文件哈希、相关读取器代码、转换/OCR 配置、模型和依赖版本 |
| 字段层 | 候选、单位、证据、核对状态、校验结果 | 读取层缓存键、字段定义及提取/校验/归并规则 |

- 有效读取结果生成一次；调字段规则优先重放读取缓存，改读取器只重跑相关格式/路径。边界不清时扩大失效范围；失败、超时或不完整结果不作成功缓存。
- 原件原地读取，不复制进样例、夹具、源码或发布包。业务文本缓存仅放任务临时目录（如 `D:/bag/tmp/trade-document-tests/`），结束说明保留位置或清理情况；持久报告仅保留哈希、字段名、计数、结果及代码/环境指纹。
- 先确认现有工具实际能力（`--help` 或入口片段）。缓存未实现时不能声称已经支持；小测试可用内存，反复调试才评估增加重放工具，不因此中断已授权工作。

## 调试与验收

1. 用失败文件与一个有效对照定位读取、OCR、字段或界面问题，补有意义的合成回归。OCR 环境故障先隔离做最小加载/单页检查，不逐份资料试版本。
2. 每次修改只跑相关测试和受影响文件；记录检查名、源文件/代码/环境指纹、结果和证据位置。指纹未变且无新疑点时复用，不重复运行或累计计算同一检查。
3. 代码稳定后，对用户指定范围做一次最终版本的完整上传 API 验收，实际读取不可用缓存代替；核对关键值、单位、错误归并、来源证据及原件未改动，不能仅看字段存在或 HTTP 200。失败修复后重验受影响范围，确保全部结果覆盖最终版本。
4. 浏览器只验证主要失败路径和修改的交互。上传逻辑未变且 API 已覆盖时，不再逐份上传整批资料；批量队列/文件选择问题须验证相应批量行为。版式问题只渲染相关页，截图只留关键状态，未变化页面不重复截图。
5. 仓库必需检查保留；昂贵全应用回归在稳定版本集中跑一次，通过后仅因相关改动、失败或新疑点重跑。纯说明/技能编辑只验证结构、链接及约束保留，不重新识别真实文件或跑业务全套。

不得省略失败复现、关键值与来源正确性、最终版本覆盖或用户明确要求的验收；不猜值、不抹去真实文件间的差异。节省效果只报可核实的执行次数、输出量等，不编造 token 或扣量百分比。

## 按需使用的入口

以下均相对 `packing-eval/`；以当前工具实现为准，不假定已支持缓存、子集或逐值断言。

- 模块回归：`application/web_env/Scripts/python.exe -m unittest discover -s features/trade-documents/tests`
- 产品导入：`node features/trade-documents/tests/test_product_import.cjs`
- 真实识别：`features/trade-documents/tests/audit_real_documents.py`
- Word/PDF 来源预览：`features/trade-documents/tests/audit_source_previews.py`
- 历史验收仅遇到相关问题时读取：`features/trade-documents/tests/recognition-verification.md`、`features/trade-documents/tests/source-preview-verification.md`。历史结果仅作基线，不替代当前验证。
